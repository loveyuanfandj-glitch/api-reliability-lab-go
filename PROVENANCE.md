# Provenance and clean-room statement

This repository is an independently designed portfolio project built from a
blank repository with synthetic data and public specifications.

It contains no source code, configuration, logs, schemas, traffic captures,
screenshots, benchmarks, internal documentation, or proprietary design
artifacts from any current or former employer.

The domain model is intentionally generic. Names, routes, limits, failure
scenarios, metrics, and test data were created specifically for this project.
